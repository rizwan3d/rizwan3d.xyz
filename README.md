# Rizwan3d

Rizwan3d is Muhammad Rizwan's personal blog and portfolio website.

The site collects writing about software engineering, AI agents, RISC-V, compilers, assemblers, virtual machines, C#, .NET, PHP, and web technologies. It is built as a focused publishing space for articles, project notes, learning logs, and engineering ideas.

## What This Website Includes

- A homepage with recent writing and a short introduction.
- A blog archive for published articles.
- Individual posts written in Markdown.
- An about page with profile links and project context.
- Contact, privacy, terms, and cookie pages.
- RSS, Atom, and JSON feeds for readers.
- Search support for finding posts.

## Writing

Blog posts live in the `writing` folder and are organized by year, month, and day. Each post includes front matter for details such as title, date, description, and tags.
